# 웹사이트 자산 요청 목록 (연구소 → 드라이브)

`redesign/sumuk` 브랜치의 새 inzeum.com 은 아래 자산이 들어오면 임시 이미지를 교체하는 것만으로
완성됩니다. 파일은 원본 해상도 그대로, 드라이브의 한 폴더에 아래 이름의 하위 폴더로 모아 주시면
그대로 반영하겠습니다.

## 1. 꼭 필요한 것 (임시 자산을 대체)

| 폴더 | 무엇 | 왜 | 규격 |
|---|---|---|---|
| `01-sumuk/` | 연구소가 소장·승인한 **수묵 산수화 1점** (산), 가능하면 소나무 1점 | 홈 첫 화면의 "머무는 산"과 프로그램 페이지 배경. 지금은 생성 이미지 | 흰 종이(한지)에 먹, 정면 스캔/촬영, 가로 3200px 이상, 가로:세로 2:1 이상 |
| `02-seal/` | 연구소 또는 교수님 **낙관(인장)** 이미지 | 브랜드의 유일한 주홍 점. 생성하지 않고 실물만 사용 | 흰 배경 스캔, 1000px 이상 |
| `03-professor/` | 김주환 교수 **고해상도 인물 사진 2~3장** (강연 중 / 명상 중 / 정면) | 소개 페이지의 명상 사진은 773px 로 화면에서 흐려짐 | 세로 3000px 이상, 원본 JPG/RAW |

## 3. 글 (소식 페이지)

소식 페이지는 지금 연혁 수준의 목록입니다. 아래가 있으면 실제 "소식"이 됩니다.

- 2024~2026 주요 공지·모집 글 원문 (유튜브 커뮤니티/블로그/이메일에 올린 것) — 제목, 날짜, 본문, 링크
- 기초과정 다음 기수 모집 일정과 신청 링크
- 심화과정 2기 계획이 있다면 시점
- 언론 보도 링크 (있다면)
